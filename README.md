## Drug-Centric Adaptive Diffusion and Path Learning for Drug–Target Interaction Prediction

This repository contains the implementation of DCA-DTI, a network-based framework for drug–target interaction prediction.

## Pipeline

The complete pipeline consists of four sequential stages:

PPR Computation  
↓  
Random Split & Path Construction  
↓  
Graph Cache Building  
↓  
EAGAT Model

The notebooks should be executed in this order.

Data
The data/ directory contains the input datasets and feature files required by the pipeline.
The protein embedding file is provided separately due to its size.
Protein embeddings:
https://drive.google.com/file/d/1qmrGcinnI5Q0ZT4mhUlyrzybv3CTcAPu/view?usp=sharing⁠
Download PROTEIN_EMBEDDINGS_8142.csv and place it in: data/PROTEIN_EMBEDDINGS_8142.csv


Outputs
All intermediate and generated files are stored in the outputs/ directory.
The outputs generated by each stage are used by the subsequent stage of the pipeline. 
The graph cache files are also generated in outputs/ during execution.

Execution
Run the notebooks sequentially:
1. PPRComputation.ipynb
2. RandomSplit_PathConstruction.ipynb
3. GraphCacheBuilding.ipynb
4. EA_GAT.ipynb
5. 
The pipeline is designed to be executed sequentially, with each stage using the outputs generated by the preceding stage.
Requirements
The implementation is designed to run in Google Colab. Required dependencies are installed in the notebooks where necessary.

Reproducibility
To reproduce the pipeline:
Download the protein embedding file from the link above.
Place it in the data/ directory.
Open the notebooks in Google Colab.
Execute the notebooks in the order specified above.
Generated intermediate files and caches will be stored in outputs/.
